# JasyptSmallTools

基于 [Jasypt](http://www.jasypt.org/) 1.9.3 的 PBE 加密 / 解密 / 密钥找回 Swing GUI 小工具。

## ⚠️ 合法使用声明

本工具的「密钥爆破」功能(掩码爆破、字典爆破)仅用于对**你本人拥有或已获得明确授权**的密文进行密码找回。
对他人密文进行未授权破解可能违反相关法律法规,由此产生的一切后果由使用者自行承担。
请勿将含有真实密文或真实密钥片段的脚本(如 `PBEDecryptor.java` 的运行参数)提交到版本库。

## 功能

- **加密**:输入明文与密码,输出 Base64 密文。
- **解密**:输入密文与密码,还原明文。
- **密钥爆破**:已知密钥前缀时,按掩码规则枚举未知部分;或基于字典文件逐行尝试。爆破在后台线程执行,可随时停止。

> 安全提示:本工具固定使用 `PBEWithMD5AndDES` 算法,以兼容历史密文。该算法(MD5 + DES)按现代标准已不安全,**请勿用于保护新数据**。若需加密新数据,应改用 `PBEWithHMACSHA512AndAES_256` 等强算法并显式提高密钥派生迭代次数。

## 掩码规则

`掩码爆破` 的「掩码规则」字段每个占位符对应密钥中一个待枚举位置:

| 占位符 | 含义 |
|--------|------|
| `?u` | 大写字母 A-Z |
| `?l` | 小写字母 a-z |
| `?d` | 数字 0-9 |
| `?h` | 小写十六进制 0-9a-f |
| `?H` | 大写十六进制 0-9A-F |
| `?s` | 特殊字符 |
| `?a` | 所有可打印 ASCII |
| `?b` | 所有字节值 0-255 |
| 其他字符 | 按字面量固定 |

例:已知密钥前缀 `Key`,规则 `?d?d?u` 表示在其后枚举「两位数字 + 一位大写字母」。

## 构建与运行

### 使用 Maven(推荐)

```bash
mvn clean package
java -jar target/jasypt-small-tools-0.0.1.jar
```

`maven-shade-plugin` 会生成包含 jasypt 依赖的可执行 fat-jar,主类为 `GUI`。

### 命令行掩码爆破示例

```bash
java -cp target/classes:lib/jasypt-1.9.3.jar PBEDecryptor <base64密文> <已知密钥前缀> [后缀长度]
```

后缀长度默认为 4,字符集为 `0-9A-Z`。

## 依赖

- `org.jasypt:jasypt:1.9.3`(Maven 自动拉取;`lib/jasypt-1.9.3.jar` 为离线副本)
- JDK 17+(项目目标 LTS)
