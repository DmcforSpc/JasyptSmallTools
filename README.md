# Jasypt 加密解密工具

## 功能特性
- 支持加密、解密操作
- 支持密钥爆破功能
- 多种字符集规则支持

## 使用说明

### 加密功能
1. 选择"加密"标签页
2. 输入明文和密钥
3. 点击"加密"按钮
4. 密文将显示在结果区域

### 解密功能  
1. 选择"解密"标签页
2. 输入密文和密钥
3. 点击"解密"按钮
4. 明文将显示在结果区域

### 密钥爆破功能
1. 选择"密钥爆破"标签页
2. 输入密文
3. 设置已知密钥部分（可选）
4. 输入字符集规则
5. 点击"开始爆破"按钮
6. 结果将显示在结果区域

## 字符集规则
- ?l = 小写字母 (abcdefghijklmnopqrstuvwxyz)
- ?u = 大写字母 (ABCDEFGHIJKLMNOPQRSTUVWXYZ)
- ?d = 数字 (0123456789)
- ?h = 小写十六进制 (0123456789abcdef)
- ?H = 大写十六进制 (0123456789ABCDEF)
- ?s = 特殊字符 (!"#$%&'()*+,-./:;<=>?@[\]^_`{|}~)
- ?a = 所有可打印字符 (ASCII 32-126)
- ?b = 所有字节值 (0x00-0xff)

## 示例
加密：
```
明文：HelloWorld
密钥：secret
规则：?a
```

爆破：
```
密文：U2FsdGVkX1+...
已知密钥部分：sec
